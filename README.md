# 面向对象遥感分割分类流水线（手写复刻 eCognition 思路）

> Python + rasterio + scikit-image 复现面向对象影像分析（OBIA）全流程：
> **手写多尺度区域生长分割（Baatz & Schäpe 异质性准则）→ 图斑光谱/纹理/形状特征融合 → RandomForest 地类划分 → 分割矢量 GeoJSON + 分类栅格 GeoTIFF**。
> 核心分割逻辑完全手写，不调用任何现成面向对象解译 SDK（eCognition/OTB/SAM 等）；skimage 的 SLIC 仅按约束作为对照基线入图。

**一句话结论（512²×4 波段合成场景，seed=20260829）**：与同架构像素级 RandomForest 相比，面向对象方法总体精度持平（0.959 vs 0.958），但**椒盐率降低约 11 倍（0.0018 vs 0.0193）、真实边界还原 F1 提高 49%（0.481 vs 0.323）**，且产物天然是矢量图斑，可直接入库制图。

## 2. 面向对象分割原理（eCognition 多分辨率分割的复刻）

### 2.1 为什么要"面向对象"

高分辨率遥感影像里，地物是以"图斑"（田块、水面、建筑区）为基本单元的：图斑内部像素光谱相近但绝不相同（噪声、纹理），图斑边界处存在混合像元。逐像素分类只利用单像素的 4~6 维谱向量，对噪声极其敏感——这就是经典"椒盐"现象；而人眼判读用的是**谱 + 纹 + 形 + 上下文**的综合。面向对象方法把分类单元从像素升级为同质图斑：分割先按"异质性最小"原则把像素聚成图斑，再以图斑为单位提取特征并分类。eCognition 是这一思想的商业标杆，其核心算法即 **多分辨率分割（Multiresolution Segmentation, Baatz & Schäpe 2000）**。

### 2.2 异质性准则（合并代价）公式与推导

把每个图斑记为对象 $o$，其像素数 $n(o)$、各波段标准差 $\sigma_b(o)$、周长 $b(o)$（像素边数）、外包矩形周长 $l(o)$。合并两相邻对象 $a,b$ 得 $m$，合并代价为：

$$f(a,b) = w_{color}\,\Delta h_{color} + w_{shape}\,\Delta h_{shape},\qquad w_{color}=1-w_{shape}$$

**光谱异质性增量**——合并后总方差只增不减（方差分解的三角不等式性质），其增量即"用两个对象拼成一个对象所新增的光谱信息量"：

$$\Delta h_{color} = \sum_b w_b\left[\,n_m\sigma_{m,b} - n_a\sigma_{a,b} - n_b\sigma_{b,b}\,\right]$$

其中 $n\sigma$ 口径等价于 $n$ 个像素对总方差的贡献（$\sum(x-\bar x)^2 = n\sigma^2$ 的一阶近似，eCognition 原文即按 $n\sigma$ 记账）。同类相邻对象合并时 $\Delta h_{color}\approx 0$，跨类合并时它随类间光谱距离迅速放大——这就是分割能"贴着地物边界停住"的数学根源。

**形状异质性增量**——纯光谱准则会长出细长蛇形对象，形状项用两个互补的几何惩罚纠偏：

$$\Delta h_{shape} = w_{smooth}\,\Delta h_{smooth} + w_{cpt}\,\Delta h_{cpt},\qquad w_{smooth}=1-w_{cpt}$$

$$\Delta h_{smooth} = n_m\frac{b_m}{l_m} - n_a\frac{b_a}{l_a} - n_b\frac{b_b}{l_b}\qquad\text{（光滑度：周长/外包矩形周长，越接近 1 越"填满"外包框）}$$

$$\Delta h_{cpt} = n_m\frac{b_m}{\sqrt{n_m}} - n_a\frac{b_a}{\sqrt{n_a}} - n_b\frac{b_b}{\sqrt{n_b}}\qquad\text{（紧致度：周长/\sqrt{面积}，圆/方形最小）}$$

三个参数由此而来：**scale**（尺度阈值，$f$ 超过它就停止合并）、**shape**（$w_{shape}$，形状项权重）、**compactness**（$w_{cpt}$，紧致度在形状项内的权重）。

### 2.3 算法流程（本实现，`obia/segment.py`）

1. **初始化**：每个像素为独立对象；建立 4 邻域邻接图（dict-of-dict，值 = 共享边界长度）；所有相邻像素对的合并代价入优先队列。
2. **贪心合并循环**：弹出全局最小代价对 $(a,b)$——
   - 惰性失效：若 $a,b$ 任一已被合并（union-find 根检查），跳过；
   - 若 $f > scale$：**停止**（堆顶即全局最小，无需再看）；
   - 否则合并：统计量 $n,\sum x,\sum x^2$、周长（$b_m = b_a+b_b-2s$）、外包框按分量取并；邻接表按边权加和融合；与新邻居重算代价入堆。
3. **收尾**：union-find 路径压缩（numpy 指针倍增），连通根重映射为连续图斑编号 1..K。

三个关键实现性质：

- **确定性/可复现**：代价为连续浮点 + 弹堆顺序确定 + 并入固定取小 id，同参数两次运行 label 完全一致（测试 B5 验证）。
- **多尺度天然嵌套**：合并序列与 scale 无关，scale 只截断序列 → scale₂>scale₁ 的分割必为 scale₁ 的再合并（测试 B9 验证）。这正是 eCognition"多尺度层级"的来源：一次合并树，任意尺度免费取用。
- **复杂度**：约 N 次合并 × 平均邻居数次 O(波段数) 代价计算。512²×4 波段纯 Python 61 s（26 万次合并）；参数扫描 12 个分割点合计约 13 分钟。

### 2.4 与 eCognition 的对应关系

| eCognition 概念 | 本实现 |
|---|---|
| Multiresolution Segmentation | `multiresolution_segment()`，逐对合并 + 优先队列 |
| Scale Parameter | `scale`（合并代价阈值，堆顶超阈值即停） |
| Shape / Compactness 权重 | `shape` / `compactness` |
| 对象异质性（光谱+形状） | Baatz & Schäpe 公式逐项复刻（2.2 节） |
| 多尺度层级 | 同一合并树按 scale 截断，层级严格嵌套 |
| 分类（标准最近邻/SVM） | 图斑特征 + RandomForest（sklearn） |

## 3. 图斑特征体系（19 维融合）

| 组 | 特征 | 说明 |
|---|---|---|
| 光谱（9） | `mean_b0..b3`、`std_b0..b3`、`brightness` | 对象内各波段均值/标准差（方差）与全谱亮度——把"像素谱"平均成"图斑谱"，方差即对象内异质性 |
| 比值（2） | `ndvi`、`ndwi` | 对象级 (NIR−R)/(NIR+R)、(G−NIR)/(G+NIR) |
| 纹理（4） | `glcm_contrast / homogeneity / entropy / asm` | **手写对象内掩膜 GLCM**：只统计对象内部相邻像素对（右向+下向），16 级分位数量化灰度、对称化——区别于方块窗口 GLCM（会把邻居像素算进来） |
| 形状（4） | `shape_index`、`bbox_fill`、`elongation`、`area` | 周长/√面积（eCognition 同名指数）、矩形度、长宽比、面积 |

分类器为 sklearn `RandomForestClassifier(300 棵, seed=20260829)`，图斑按真值多数票标定类别，60/40 分层划分训练/测试；像素级对照给同架构 RF [4 波段 + 5×5 局部均值/标准差]。

## 4. 实验设置

内置合成场景（`obia/synthetic.py`，seed=20260829 可复现）：512²×4 波段（B/G/R/NIR），5 类地物（水体/林地/耕地/裸土/建设用地）× 12 个大类分区 × 70 个 Voronoi 田块；每类有专属纹理（林地高频颗粒、耕地随机方向条垄、建设用地 8 px 块状、裸土中频斑块、水面平滑），逐像素高斯噪声 σ=0.028，田块级光谱抖动，图斑交界 1 px 混合像元压暗。**自带像素级真值与图斑真值**，使精度/边界贴合度可以严格量化——这也是选合成数据而非真实影像的原因：真实影像没有像素级真值，无法把"对比实验"做成"对照实验"。

评估口径（三个，各管各的）：

- **全图 OA**：分类图 vs 像素级真值，逐像素统计——主精度指标；
- **椒盐率**：分类图中像素与其 3×3 邻域多数类不同的占比——碎斑程度；
- **边界贴合度 F1**（容差 2 px 双向匹配）：分类结果边界 vs 真值**地类**边界（像素/对象同台公平）；分割敏感性扫描中另用 label 图边界 vs 真值**图斑**边界（衡量分割本身）。注：同类相邻田块边界在地类边界中不可表达，故该口径对分割贴合更宽容、对分类更严格。

## 5. 主结果：像素级 vs 面向对象（512²，scale=10 / shape=0.2 / compactness=0.5）

| 指标（全图口径） | 像素级 RF | **面向对象 RF（本流程）** | skimage SLIC 对照 |
|---|---|---|---|
| 分类单元 | 262,144 像素 | **440 图斑** | 441 超像素 |
| 总体精度 OA | 0.958 | **0.959** | 0.945 |
| 椒盐率（越低越干净） | 0.0193 | **0.0018（↓11 倍）** | 0.0002 |
| 边界贴合 F1（vs 地类真值） | 0.323 | **0.481（+49%）** | 0.285 |
| 分割/特征化耗时 | —（免分割） | 61 s（手写 MRS） | 1 s（k-means） |
| 产物形态 | 栅格（逐像素） | **矢量图斑 + 栅格双份，直接入库制图** | 栅格 |

对比图：`results/figs/fig2_pixel_vs_object.png`（上：RGB/真值/像素级；下：对象级/两套误差图——红色错分像素在像素级图中沿边界呈带状弥散，在对象级图中大幅收缩）。

**机理讨论（为什么 OA 持平但质量碾压）**：

1. **椒盐噪声**：像素级 RF 对每个 4~16 维谱向量独立判决，类内噪声（σ=0.028）+ 纹理（建设块状 σ=0.085）使错分像素在同类区域内呈孤立散点（椒盐率 1.9%）。图斑级判决以 1370 px 平均均值/方差为证据，噪声被 √n 衰减，错分只发生在"整个图斑跨类"时（0.18%）——矢量制图前无需任何 majority filter 后处理。
2. **边界行为**：像素级的错分集中在混合像元带（边界 1~2 px），表现为"边界毛边"；对象级的边界继承自分割，而分割代价在跨类处急剧上升（2.2 节），使对象边界自动贴住田块壕沟 → 边界 F1 高 49%。
3. **OA 为什么没赢**：本合成场景类间光谱距离大（NDVI 差 0.3+），像素级 RF + 局部纹理特征本就接近其性能上限（0.958）；对象级的剩余错误来自跨界图斑整斑错分——一个 1400 px 图斑错分即损失 0.5% OA，而像素级错分是弥散的。真实数据中类内变异更大、纯谱可分性更差，OBIA 的 OA 优势通常更明显（文献共识）。
4. **何时 OBIA 划算**：需要矢量产物（国土调查/变化检测图斑）、需要纹理/形状语义、需要制图级图面质量；反之若只需快速粗分类且算力受限，像素级也有其位。

## 6. 参数敏感性分析

扫描协议：512² 场景，逐参数变化、其余固定（主参数 scale=10 / shape=0.2 / compactness=0.5），每点完整走"分割 → 特征 → RF"。原始数据 `results/sensitivity.csv`，曲线 `results/figs/fig3_sensitivity.png`。

### 6.1 scale（尺度阈值）——最重要参数

| scale | 图斑数 | 平均面积(px) | 分割边界 F1(vs 图斑) | 图斑级分类 OA* |
|---|---|---|---|---|
| 5 | 925 | 283 | 0.249 | 0.988 |
| **10（主）** | **440** | **596** | **0.251** | **0.989** |
| 20 | 191 | 1372 | 0.239 | 0.984 |
| 40 | 93 | 2819 | 0.219 | 0.978 |
| 80 | 43 | 6096 | 0.204 | 0.953 |
| 160 | 21 | 12483 | 0.171 | 0.905 |

\* 测试图斑口径（每点同协议，横向可比）；全图口径主尺度为 0.959。

- **对象数随 scale 单调下降**（925→21，测试 B7），平均面积近似指数增长——scale 实为"异质性预算"：预算越大，允许存在的对象内总方差越大。
- **分类 OA 随 scale 单调下降**（0.988→0.905）：scale 大 → 对象越过田块边界吞并异类像素 → 整斑错分。**过分割（scale 小）对分类几乎无害**（图斑更纯），只是矢量更碎、耗时更长。
- **分割边界 F1 在 scale≈10 达峰**后下降：细尺度精确率低（对象边界多在田块内部），粗尺度召回率低（田块边界被吞并跨越）。
- 实践法则：**"分割尺度服从应用"**——图斑级制图/变化检测取"对象≈目标图斑"的尺度；分类精度优先则取"对象不跨界"的更细尺度；两种需求冲突时优先保证"对象纯度"，宁可过分割。

### 6.2 shape（形状权重）与 compactness（紧致度）

shape 扫描（scale=10、compactness=0.5 固定）：

| shape | 图斑数 | 分割边界 F1(vs 图斑) | 图斑级分类 OA* |
|---|---|---|---|
| 0.0 | 131 | **0.405** | **0.992** |
| 0.1 | 271 | 0.288 | 0.985 |
| 0.2（主） | 440 | 0.251 | 0.989 |
| 0.3 | 663 | 0.237 | 0.988 |
| 0.5 | 1001 | 0.229 | 0.991 |

compactness 扫描（scale=10、shape=0.2 固定）：

| compactness | 图斑数 | 分割边界 F1 | 图斑级 OA* |
|---|---|---|---|
| 0.0 | 101 | **0.367** | 0.960 |
| 0.3 | 344 | 0.250 | 0.983 |
| 0.5（主） | 440 | 0.251 | 0.989 |
| 0.8 | 685 | 0.238 | 0.981 |

- **shape/compactness 越大 → 图斑数越多**（形状项抬高合并代价 → 提前触阈值 → 过分割加剧）：shape 0→0.5 对象数 131→1001。
- **本合成场景 shape=0 反而全面最优**（对象最少、边界 F 最高、OA 最高）：纯光谱准则下，"负形状偏移"使狭长的混合像元壕沟条带被两侧自由吸收，对象边界直接贴住田块边线。**但这不意味着 shape=0 万岁**——本场景以光谱可分的面状田块为主、形状语义弱；真实数据中道路/建筑等形状语义强的目标需要形状项维持对象形态，eCognition 惯用 Shape=0.1~0.3。
- **一个重要机制（实测发现，见 6.1 尾注）**：形状项可以为**大负值**——吞并狭长边界条带（混合像元壕沟被切成的细条对象）时，该条带自身的 $b/\sqrt n$、$b/l$ 惩罚极重，合并使总形状代价骤降，负增量抵消光谱代价，使合并代价跌破小阈值，引发**链式吸收直至全图并一**。128² 场景 scale=16 即触发（全图并一）；compactness=0（光滑度主导）在 512² 也表现出同款加速（101 个对象、F=0.367）。eCognition 同样存在此现象（scale 过大整图并一）。含义：**scale 的"安全上限"与 shape/compactness 取值耦合**，换参数后须重新标定，不能沿用旧直觉。

### 6.3 与 skimage SLIC 对照

SLIC（k-means 超像素，n_segments≈440 与主流程对齐，同一套下游特征+RF）：

| | 手写 MRS（本流程） | SLIC |
|---|---|---|
| 全图 OA | **0.959** | 0.945 |
| 椒盐率 | 0.0018 | **0.0002** |
| 边界贴合 F1（vs 地类） | **0.481** | 0.285 |
| 耗时 | 61 s | **1 s** |

解读：SLIC 优化目标是"颜色均匀 + 紧致"，超像素极其平滑（椒盐率最低）但**对弱对比边界（田块间混合像元壕沟）不敏感**——超像素跨界吞并，整斑错分拖低 OA，边界 F 落后 70%。手写 MRS 的异质性准则在跨类合并处代价陡增，边界停位准得多。SLIC 快 60 倍，适合做快速粗分割或候选区域生成；要"贴地物边界的图斑"还得靠异质性准则驱动。此外 SLIC 无跨尺度嵌套层级。（skimage 系按任务约束仅作对照，不进主流程。）

## 7. 局限与扩展方向

- **性能**：纯 Python 合并循环 61 s/512²，未做 NUMBA/Cython 加速；邻接图 dict-of-dict 内存 ~1 GB 峰值（512²）。工程化首选 numba 重写热循环。
- **分割**：单尺度阈值停止，未实现 eCognition 的"自底向上逐层生成对象层级"交互模式（但嵌套性已验证，等价于免费层级）；无边界对象特判（影像边缘对象周长含图框）。
- **分类**：训练/测试为随机划分，空间自相关下双方都有乐观偏差（对比仍公平）；未做半自动样本选择（eCognition 典型工作流）。
- **扩展**：接入真实 GeoTIFF 已留口（`--config/--truth`）；可加对象级上下文特征（邻接对象类别先验）与 CRF/MRF 平滑。
